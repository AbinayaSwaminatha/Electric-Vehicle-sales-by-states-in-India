Electric Vehicle sales by state in India

Dataset: Electric Vehicle sales by state in India
https://www.kaggle.com/datasets/mafzal19/electric-vehicle-sales-by-state-in-india

About:
This project presents a comprehensive analysis and interactive dashboard of Electric Vehicle (EV) sales across Indian states, using real-world data sourced from government portals and public datasets. The goal is to uncover trends, regional adoption patterns, and vehicle type preferences to better understand the growth of EV adoption in India.
